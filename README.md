# SANA — Software Testing Project

## Project Overview
SANA is a personal development tracker designed to help users set goals, plan actions, track progress and adapt their strategies.

## Project Objective
The objective of this project is to prepare and document software testing activities for the SANA application.

## Testing Scope
- Goal creation and validation
- Deadline management
- Task completion
- Progress tracking
- Kazakh, English and Russian language switching
- Data persistence
- Responsive interface

## Repository Contents
- README.md — project overview and testing scope
- test-cases.md — planned test scenarios
- bug-report.md — bug report template

## Testing Status
Preparation in progress. Test results must be recorded only after actual execution.
